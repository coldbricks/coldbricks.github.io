How to watch NAS movies on Meta Quest 3

Install Finally VR Video Player, add your SMB share, save, then play. The headset streams from Synology, TrueNAS, Unraid, or a Windows PC on the same Wi-Fi. Files stay on your server. Coldbricks never sees them. You do not need Plex, a catalog account, or a USB copy of the whole library.

This is the job Finally was built for. Local storage and SMB are first-class sources — not a buried “network” afterthought. Hardware playback goes up to 8K as a decoder ceiling on Quest 3; whether your Wi-Fi can feed that bitrate is a network fact, not a slogan.

Setup

From zero to a picture.

  1. Install Finally from the Meta Horizon Store. Quest 3, 3S, Pro, and Quest 2.
  2. Share the folder over SMB on the same network as the headset. Write down host (IP or name), share, username, password.
  3. In Finally open SRC, add SMB, sign in to the server, pick the shared folder.
  4. Save the source, then open a title.

The field manual is the authority for the build in your Lobby — buffer sizes, the live rebuffer banner, and the exact SRC chrome in that build.

Servers

Windows, Synology, TrueNAS.

Windows PC

Share the movies folder (Properties → Sharing). Use a local account that can read the share. On the Quest, the host is the PC’s LAN IP. Private Wi-Fi, not guest isolation — the headset must see the PC.

Synology / TrueNAS / Unraid

Enable the SMB service, create a share that holds the library, give a user read permission. Finally talks SMB; it does not need the NAS vendor’s mobile app. If you already run Plex, Finally can Direct Play from a user-supplied local PMS URL + token — no cloud login, no transcode. SMB is still the no-transcode path for files you already named correctly.

What Finally does not do

It does not upload your library. It does not transcode on a Coldbricks server. It does not require an account. Optional nearby discovery can find SMB hosts on the LAN; credentials still stay on the headset and only go to the server you named.

FAQ

NAS questions.

Can Quest 3 play 8K from a NAS?

Finally’s hardware path goes up to 8K as a decoder ceiling on Quest 3. Whether your Wi-Fi and NAS can feed that bitrate is a network fact, not a slogan. Use a wired NAS and 5/6 GHz Wi-Fi to the headset. The in-player rebuffer readout tells you if the pipe is the problem.

SMB vs Plex vs copying files

Copying is simplest and slowest to update. Plex is a catalog you already maintain. SMB is “the folder on the server, as it is.” Finally speaks all three. Plex Direct Play is a user-supplied local PMS URL + token; no cloud login, no transcode. Start with SMB if the files are already organized.

Skybox or 4XVR for NAS instead?

They also speak SMB. Finally is free, has no account, and keeps per-title projection after a one-time consent. Read vs Skybox and vs 4XVR.
