02 · cockpit

Built for the headset.

Native OpenXR theater. SIMPLE for daily transport. PRO when you want the whole board. One tracked controller can reach every critical control.

  • SIMPLE and PRO cockpits — daily transport in SIMPLE; placement, color, loops, and stats waiting in PRO.
  • True scene dolly — move closer without wrecking world scale. Stick click homes distance and zoom.
  • Lie-back tilt follow — the picture stays upright to your face. Menus stay world-anchored.
  • Refresh-rate matching — cadence-aware display hints for 24 / 25 / 30 / 60 fps content. Not fake frame interpolation.

  • Watch Together — two headsets on a private LAN, same media bytes, no account and no Internet room.

08 · questions

Daily-use FAQ

What is Finally, in one sentence?

A native OpenXR VR video player for media you already own — local files and network shares, no catalog and no account.

How do I watch a NAS / SMB library on Quest 3?

Install Finally from the Horizon Store, open SRC, add the SMB server, pick the shared folder, and save. Playback streams from your machine. Coldbricks never sees the files. The field manual has the exact first-hour path.

Is this a Skybox or 4XVR alternative?

If you want a free player that treats local + NAS as the product, remembers projection, and does not run Coldbricks telemetry — yes. Store builds still check Meta entitlement. Nearby discovery, Watch Together, and optional bug-report Send are on the privacy map. If you want Skybox environments, 4XVR’s densest format board, or HereSphere’s optical microsurgery, those apps still earn their price. Read the comparison.

Does it play VR180, 360, SBS, and fisheye?

Yes. Filename tags and frame geometry pick a lens; you can override; the override is stored per title. Flat 3D movies use SBS / top-bottom packing with a one-press 2D exit.

Is it free? What’s the catch?

Free on the Meta Horizon Store. No ads, no subscription, no account. Optional support links live on the web manual, not in the player. Galaxy XR shares the same player family; the Quest store listing is the current public install path.

What do you collect?

Nothing automatically to Coldbricks. Library index, credentials, and playback memory stay on the headset. Optional Submit Bug Report creates a ZIP locally and sends it only if you press Send. Meta store builds check entitlement with Meta (pass/fail). Other optional network paths are listed in the privacy policy.

Is Finally free on Meta Quest?

Yes. Finally is a free native player for local files and NAS libraries on Quest 3 / 3S / Pro / 2. Paid apps still win specific jobs — Skybox for environments, 4XVR for a dense format board, HereSphere for optical calibration. Start here if you do not want to pay to play your own files.

Which headsets?

Meta Quest 3, Quest 3S, Quest Pro, and Quest 2 on the Horizon Store. Hardware decoder ceiling up to 8K is a Quest 3 proof, not a Quest 2 panel claim. Galaxy XR shares the same player family; the Quest listing is the current public install path.

If you have a media collection and a Quest, start here. Free on the Meta Horizon Store. The field manual is the authority for the build in your Lobby.
