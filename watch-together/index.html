Watch Together without a login

Finally VR Video Player pairs two Quest headsets on your private LAN. Host / Join lives under Lobby CFG. Both headsets need the same media bytes — local copies or the same NAS path. TLS between peers. Coldbricks receives no room. It is not casting, not Chromecast, not a public lobby. Free.

Versus Skybox rooms

Cloud movie night is a different product.

Skybox watch-together is account-gated and server-brokered. Finally’s is the LAN version of “we both have the file.” If you need strangers in a cinema, that is not this. If you need a second headset on the couch, this is. Details in the field manual. Privacy: no Coldbricks telemetry.
