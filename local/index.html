How to watch local videos on Quest 3

Install Finally, copy a video onto the headset, SCAN, press play. That is the whole first hour. MP4, MKV, VR180, 360, fisheye, SBS, photos — same vault. No catalog login. When the library grows past what you want on the headset, switch the same player to SMB / NAS.

First hour

One known-good file.

  1. Install Finally VR Video Player.
  2. Connect the Quest over USB and copy a file you trust (a short 1080p MP4 is a better first test than an 8K 180).
  3. Drop it where you will find it — Movies/Finally is the manual’s fastest path — or use Add videos folder / Add files through the system picker.
  4. In the Lobby, press SCAN. Open the row. If projection is wrong, fix it once; after OVERRIDE consent it sticks. See VR180 / 360.

USB sticks Finally can see are SAF / OS-exposed volumes, not host MSC. A yanked drive may need a fresh grant. USB optical DVD is a narrower Quest path, not the everyday one.

Next

When local fills up.

Quest storage is not a NAS. Finally’s SMB path is the same product, not a different app. Keep using local for travel and the share for the shelf.
