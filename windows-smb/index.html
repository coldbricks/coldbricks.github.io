How to play PC videos on Quest 3 without a cable

Share the folder over SMB, put the Quest on the same Wi-Fi, add the share in Finally. No Plex. No Virtual Desktop required for this job. Files stay on the PC. Finally is free and collects nothing. Broader recipe: NAS / SMB.

Windows

Share, then SRC.

  1. Folder → Properties → Sharing. A local user that can read it. Password-protected sharing on is fine — Finally will ask for the user.
  2. PC IPv4 from ipconfig. Private network profile, not public. Disable AP/client isolation on the router.
  3. Finally → SRC → SMB → IP, username, password → shared-folder card → save.

Firewall: allow File and Printer Sharing on private networks. If Test fails, it is almost always Wi-Fi isolation or a wrong user, not the player. Travel / no PC: local files.

Windows already shared it. Finally just has to be told.
