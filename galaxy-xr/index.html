a place in Galaxy XR.

Finally plays local videos and photos, with SMB access to your computer or NAS. Start with one local file, then bring in the rest of your collection.

Open Google Play ↗Set up your first video

Use the account on your Galaxy XR. Google Play decides compatibility and the version available to that device.

Install through Google Play.

  1. Open the listing on your Galaxy XR. Search for Finally VR Video Player by Coldbricks, or use the Google Play link above.
  2. Choose your Galaxy XR. If using Play in a desktop browser, check that the target device is the headset before installing.
  3. Open Finally and follow the introduction. The Lobby is where you browse your collection. This walkthrough uses tracked controllers for the supported full control set. Bare-hand-only use is not a supported substitute.

If Play shows the app as unavailable, check the account and compatible-device list. An install button in a browser does not guarantee eligibility for every account or region. Contact support with the message you see, without sharing account credentials.

First video: keep it simple.

  1. Put a short video you own on the headset. A familiar 1080p MP4 makes a useful first check. Use your normal file-transfer method.
  2. Add the file or folder. In Finally, open the source/library setup and use Add files or Add videos folder. Select it in Android's system picker and grant access.
  3. Return to the Lobby and open the title. For an ordinary video, use Flat. For a side-by-side 3D movie, use Flat + SBS; a 3D file is not necessarily VR180.
  4. Get comfortable. Start with the visible playback controls. Adjust placement, and choose a virtual room or passthrough. The control reference explains the full set.

If the first file doesn't look right.

What you seeWhat to check
Two pictures side by sideFor an SBS file, turn SBS on. Keep Flat for a conventional 3D photo or movie.
People look squeezed or stretchedCheck FULL versus HALF packing and the source aspect ratio. Layout guide.
The picker cannot find the fileCheck that the transfer completed and that the file is stored on the headset or an accessible provider. Grant that folder access.
Network playback stallsCompare the same file locally, then check Wi-Fi, server access and bitrate. A local pass does not prove the network route.

Source frame rate and display refresh are different. A Quest 120 Hz result does not establish the same behavior on Galaxy XR. Store updates may arrive at different times; check the version in the Lobby when reporting an issue.
